# Strata

## Descripció

Strata és una pàgina web desenvolupada amb HTML, CSS i JavaScript que presenta una plataforma digital mitjançant diferents apartats.

## Com obrir la pàgina

1. Obrir la carpeta del projecte.
2. Accedir a la carpeta `Servidor/public`.
3. Obrir el fitxer `index.html` amb un navegador web.

Web publicada: https://dcruzadoperez.ieti.site/

## Adaptació a mòbils

S'han utilitzat media queries per adaptar el disseny a diferents mides de pantalla.

- Els elements horitzontals passen a distribuir-se verticalment.
- Les graelles redueixen el nombre de columnes.
- S'ajusten les mides dels textos, els espais i els elements per millorar la visualització en dispositius mòbils.

## Procedència dels recursos

- **Tipografies: Plus Jakarta Sans i JetBrains Mono.
- **Llibreries: Three.js i 3D Force Graph.
- **Imatges i icones: Emmagatzemades a la carpeta `assets` del projecte.
